# Python's last two major releases

Python 3.12 was [released on 2 October 2023](https://www.python.org/downloads/release/python-3120/?utm_source=newsletter&utm_medium=email). It brought [more flexible f-string parsing and even better error messages](https://www.python.org/downloads/release/python-3120/). The release also [removed the distutils package, which had been deprecated since Python 3.8](https://peps.python.org/pep-0632/). According to the release page, [Python 3.12 runs about 25% faster than Python 3.11](https://www.python.org/downloads/release/python-3120/).

A year later, [Python 3.13 was released on 7 October 2024](https://docs.python.org/3/whatsnew/3.13.html). Its headline change: [the interpreter now runs without the GIL by default](https://docs.python.org/3/whatsnew/3.13.html).

More than half of professional developers now use Python at work.
